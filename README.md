# Site Iseeer, trois pistes graphiques

Maquettes navigables du futur site de l'Iseeer, en trois pistes graphiques, pour choisir la direction à retenir.

Ouvrir `index.html` : la page d'entrée présente les trois pistes. Dans chaque piste, la barre grise du haut permet de revenir aux trois pistes ou de passer à la même page dans la piste précédente ou suivante.

Maquettes de travail de novembre 2026 : photos provisoires, formulaires factices. Les pages ne sont pas indexées par les moteurs de recherche.
